# mode-parano-assets

Bibliothèque de TOUS les contenus de mode.parano, rangés par réseau. Dépôt public : n'y mettre que du contenu
déjà publié ou prêt à l'être. RÈGLE (Julien, 15/11/2026) : on ne supprime rien ; chaque contenu créé reste ici.
Metricool lit les fichiers par leur adresse https://raw.githubusercontent.com/Aerodynamic911/mode-parano-assets/main/<chemin>.

| Dossier | Contenu |
|---|---|
| `instagram-AAAA-MM/<NN-sujet>/01.jpg … 08.jpg` | Carrousels Instagram 1080x1350. Les mêmes images servent aussi pour Facebook (post du lendemain à 12h30). |
| `pinterest-AAAA-MM/` | Épingles 1000x1500 (PNG), une par sujet. |
| `stories-AAAA-MM/` | Stories Instagram 1080x1920, publiées à la main par Julien (JJ-MM-sujet.png). |
| `tiktok-AAAA-MM/` | Posts photo et contenus faits pour TikTok. |
| `shorts-youtube/AAAA-MM-JJ-<sujet>/` | Shorts YouTube : `short.mp4`, `cover.jpg`, `spec.json`, `publication.json`. Index dans `shorts-youtube/README.md`. Générateur : `shorts-youtube/outils/make_short.py`. |
| `youtube/` | Éléments de la chaîne YouTube (bannière, etc.). |
| `incogni-2026-10/` | Ancien contenu Incogni (archive). |

Facebook n'a pas de dossier propre : il réutilise les carrousels Instagram.
Les vidéos TikTok déjà publiées avant le 15/11/2026 n'ont pas été conservées ici (fichiers non récupérés).
